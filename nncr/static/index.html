Adding pins to your Google map

  1. On the Submitted tab, tick the reports you want.
  2. Click Write map layer from selected — they move to On the map.
  3. Download NNC_Reports.kml, then in My Maps: Add layer → Import and choose it.
  4. Next time you export, the file is replaced, so anything currently On the map moves to Completed — it is already in My Maps as its own layer.

Photos. My Maps can only show an image it can fetch from the web, so pins carry the council's published photo where the tool captured its address — those appear automatically. The photos zip holds copies named to match each pin, for attaching by hand to any that have no published URL.

Everyone's submitted reports are also on the shared map, with wards and town councils.
